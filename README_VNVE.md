# VNVE 视频生成器功能说明

本项目已集成 VNVE (Visual Novel Video Editor)，允许你将跑团 Log 快速转换为视觉小说风格的视频。

## 进入方式

在电脑端界面的左侧设置栏下方，点击“视频生成器 (VNVE)”按钮即可进入视频编辑器界面。

## 功能特性

### 1. 骰子演出效果
如果角色在“角色分配”中被设置为“骰子”身份，在生成的视频中，该角色的发言将会触发特殊的骰子图标弹出动画，以增强演出效果。

**使用方法：**
1. 在“设置与角色” -> “角色分配”中。
2. 将对应的骰子角色（如 DiceBot）的身份设置为“骰子”。
3. 导出或生成剧本时，该角色的发言会自动带有骰子标记。

### 2. 插入转场效果
你可以在 Log 编辑器中直接插入转场指令，VNVE 在导入时会自动识别并添加转场效果。

**语法：**
`[Transition:效果名]`

**支持的效果名：**
- `FadeIn` (淡入)
- `Dissolve` (溶解)
- 以及其他 VNVE 支持的转场效果

**示例：**
```
主持人：天色渐晚。
[Transition:FadeIn]
主持人：第二天早上...
```
导入 VNVE 后，将在“天色渐晚”和“第二天早上”之间插入 FadeIn 转场。

## 常见问题

- **首次加载慢**：VNVE 需要加载字体和素材库，首次启动可能需要一定时间，请耐心等待。
- **浏览器兼容性**：建议使用 Chrome 或 Edge 浏览器以获得最佳体验。
